## Severity-ranked defects remaining

### P0: data integrity / false success

1. **Backup coverage:** strict failure behavior exists, but the manifest must be re-audited after Sites, Feeds, Media, native revisions, and the final navigation migration are complete.

Native autosave/revision false-success behavior was removed in PR #109. Media false-success persistence was removed in PR #106. Their remaining work is deployment/live workflow verification, not a known browser-only production-save fallback.

### P1: incomplete production behavior

1. **RBAC:** `editor_roles` exists, but role rows are not an enforced authorization boundary tied to authenticated identities.
2. **Production verification:** authenticated admin/API paths and current deployed asset hashes still need production confirmation.

### P2: engineering / interface consistency

1. Global styling is split across a large stylesheet plus numerous late-stage `*-fix`, `*-final`, and runtime override layers.
2. Printlab and AudioLab require dedicated functional and responsive audits after the remaining data-integrity work.
3. Several admin pages still need desktop/narrow-laptop/tablet/mobile normalization once their behavior is final. Taxonomy and Editor Roles were normalized structurally in PR #108 but still need live viewport checks.
